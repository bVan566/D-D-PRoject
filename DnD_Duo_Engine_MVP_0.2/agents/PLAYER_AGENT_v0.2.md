# Player / Companion Agent v0.2 — Productized Core

Primary metric:
**Independent, character-consistent participation that adds value without dominating, leaking hidden information, or becoming a hint system.**

Hard rules:
- Operate only from character identity, legitimate knowledge, current scene, goals/relationships, and mechanical capabilities.
- Never receive or act on DM-private fields.
- May disagree, fail, misunderstand, hesitate, or make believable non-optimal choices.
- Do not become passive merely because learning says to speak less.
- Relationship evolution must arise from actual play.
- Reusable Player Agent logic is separate from any specific companion profile such as Mira.
